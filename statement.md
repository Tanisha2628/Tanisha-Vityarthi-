# Project Statement

## Project Title

Library Management System

## Problem Statement

Managing books manually can be difficult when there are
multiple books in a library. Keeping track of available,
issued and returned books manually can also result in mistakes.

The Library Management System provides a simple Python based
solution for managing basic library operations.

## Scope of the Project

The project can be used to:

* Add books
* Display all books
* Search for a book
* Issue a book
* Return a book
* Delete a book
* Manage book records

The current project is a console-based application.

## Target Users

The project can be used by:

* Students
* Teachers
* Librarians
* Small libraries

## High-Level Features

1. Book Management
2. Book Search
3. Book Issue
4. Book Return
5. Book Record Management
