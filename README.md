# Library Management System

## Introduction

Library Management System is a simple Python based project
used to store and manage books in a library.
The project is console based and uses basic Python concepts.

## Problem Statement

Managing books manually can take time and may lead to
mistakes while keeping records of books.
This project provides a simple system to add, search,
issue, return and display books.

## Objectives

* Store book details
* Display all books
* Search for a book
* Issue a book
* Return a book
* Delete a book

## Features

### 1. Add Book

The user can enter the book ID, book title and author name.

### 2. Display Books

The system displays all the books available in the library.

### 3. Search Book

The user can search for a particular book by its title or ID.

### 4. Issue Book

The system allows the user to issue an available book.

### 5. Return Book

The user can return an issued book.

### 6. Delete Book

The system allows the user to remove a book from the library.
